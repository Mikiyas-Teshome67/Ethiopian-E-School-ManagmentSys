🇪🇹 Ethiopian E-School Management System




Ethiopia’s first modern, fully-featured E-School Management System!
Manage students, teachers, classes, exams, attendance, and more—all in one place. Built for Ethiopian schools to digitalize education efficiently.

🚀 Features
Student Management: Add, edit, and track student records.
Teacher Management: Assign teachers to classes and subjects.
Class & Subject Management: Organize classes, subjects, and schedules.
Attendance Tracking: Mark and view attendance for students and staff.
Exams & Results: Create exams, record grades, and generate report cards.
Notifications: Send alerts to students, parents, and teachers.
Responsive Design: Works perfectly on mobile, tablet, and desktop.
Multi-Language Support: Supports English & Amharic for Ethiopian schools.
💻 Tech Stack
Frontend: React / Angular / Flutter (choose what you used)
Backend: Node.js / Django / Laravel / Spring Boot (choose what you used)
Database: MySQL / PostgreSQL / MongoDB (choose your DB)
Mobile Support: Android / iOS apps (if any)
Extras: REST API, JWT Authentication, Role-Based Access

⚡ Installation
Clone the repo:
git clone https://github.com/Mikiyas-Teshome67/E-School.git
Navigate to the project folder:
cd E-School
Install dependencies:
npm install  # for Node.js / frontend
Configure the database in .env
Run migrations:
npm run migrate  # if using Node.js / Django / Laravel
Start the server:
npm start
Open in browser: http://localhost:3000
